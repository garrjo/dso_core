Scientific Validation Protocol

All predictions are cryptographically timestamped using OpenTimestamps (Bitcoin blockchain) before any event occurs. This provides independently verifiable proof of prediction timing.

Validation Criteria:
  • Location: ±200km from predicted epicenter (Haversine distance)
  • Timing: ±3 days from predicted date
  • Magnitude: ±0.3 from predicted magnitude
  • All three criteria must pass for a HIT
  • Timestamps: SHA-256 hash submitted to Bitcoin blockchain via OpenTimestamps
